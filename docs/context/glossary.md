# Glossário

| Termo | Definição |
|---|---|
| Booster pack | Pacote aberto pelo jogador para obter cartas. |
| Carta | Unidade colecionável usada na construção de decks e nas batalhas. |
| Era temática | Conjunto temático de cartas associado a uma era do jogo. |
| Deck | Conjunto de cartas escolhido pelo jogador para batalhar. |
| Chefe | Adversário especial que faz parte da progressão. |
| Campeão mundial | Chefe final do jogo; derrotá-lo encerra a jornada com a vitória final. |
| Elemento | Propriedade temática ou mecânica associada a uma carta. |
| Construção de deck | Escolha e combinação de cartas para formar um deck de batalha. |
| Roguelike | Estrutura de tentativas em que a derrota encerra a rodada atual e o jogador recomeça com possibilidades de progressão ou aprendizado. |
| Rejogabilidade | Capacidade do jogo de continuar oferecendo novas tentativas e possibilidades estratégicas. |
| Skill points | Pontos obtidos pelo jogador que podem ser investidos em melhorias. |
| Etapa de recompensa | Momento após uma batalha em que o jogador recebe e utiliza recompensas antes de continuar a tentativa. |
| Self-insert | Perspectiva em que o jogador se projeta diretamente como o duelista, sem um personagem principal separado. |
| Duelista | O papel assumido diretamente pelo jogador durante as batalhas de cartas. |
| Energia | Recurso gasto ao usar cartas e habilidades, com regeneração parcial ao longo dos turnos. |
| Regeneração de energia | Recuperação parcial da energia entre turnos, modificável por habilidades passivas. |
| Campo | Espaço da batalha que contém as cartas ativas de um duelista. |
| Formação | Conjunto de cartas previamente escolhido para entrar em uma batalha. |
| Upgrade | Melhoria que pode ampliar o limite de cartas em campo ou fortalecer a progressão do jogador. |
| Ressurreição | Habilidade que reativa uma carta derrotada com um estado de vida e efeitos definidos pela própria habilidade. |
| Turno | Janela de ações de um duelista; os turnos alternam entre jogador e inimigo. |
| Iniciativa | Ordem em que os duelistas começam a batalha; o jogador tem a iniciativa. |
| Limite de energia | Quantidade máxima de energia disponível; o valor inicial é 100. |
| Regeneração base | Quantidade de energia recuperada no início do turno; o valor inicial é 25. |
| Atributo base | Característica própria de uma carta/personagem que existe sem ativação, como defesa maior. |
| Potencial | Efeito ou capacidade adicional de uma carta/personagem que pode ser desbloqueado durante a batalha. |
| Habilidade ativável | Habilidade usada mediante uma ação do jogador e um custo de energia. |
| Duração | Quantidade de turnos durante a qual um potencial temporário permanece ativo. |
| Cooldown | Quantidade de turnos que deve passar antes que uma habilidade possa ser ativada novamente. |
| Pontos de vida | Valor que representa quanto uma carta ainda pode suportar antes de ser derrotada. |
| Defesa | Atributo de uma carta que participa da resolução dos ataques recebidos. |
| Dano | Efeito de um ataque que reduz a capacidade de sobrevivência de uma carta. |
| Raridade | Categoria que diferencia cartas e pode influenciar seus valores-base, sua força e sua disponibilidade. |
| Perfil de atributos | Combinação de vida e defesa que define a função de uma carta. |
| Sinergia | Relação em que cartas, atributos ou passivas combinadas produzem uma estratégia de deck. |
| Compra direta | Forma determinística de obter uma carta específica mediante um custo. |
| Rota de risco | Aquisição por booster, em que o jogador aceita resultado incerto em troca da possibilidade de obter uma carta rara. |
| Moedas | Recurso usado para comprar boosters e cartas diretamente. |
| Árvore de upgrades | Estrutura de melhorias em que o jogador investe skill points. |
| Recompensa de vitória | Moedas e skill points recebidos após vencer uma batalha. |
| Área | Etapa da progressão sequencial que contém chefes escolhíveis e um campeão fixo. |
| Campeão da área | Adversário mais forte e fixo de uma área, que funciona como nêmesis regional. |
| Nêmesis regional | Campeão da área que representa um rival pessoal recorrente para o jogador. |
| Prestígio | Progressão acumulada que pode desbloquear uma rota mais rápida para o campeão da área. |
| Rota acelerada | Caminho que pula chefes menores, reduz recompensas e leva mais rapidamente ao campeão da área. |
| Pontos de prestígio | Pontos recebidos ao derrotar chefes, em quantidade igual ao número do estágio. |
| Build | Combinação de cartas, atributos, passivas e upgrades escolhida pelo jogador. |
| Respec | Remoção de investimentos feitos em uma árvore para redistribuir skill points. |
| Inteligência artificial | Sistema que escolhe ações para controlar o turno do inimigo. |
| Arquétipo de IA | Estilo de decisão de um inimigo, como agressivo, defensivo ou focado em combos. |
| Posicionamento | Organização das cartas ativas na formação, como tanques na frente e suportes atrás. |
| Buff equivalente | Melhoria concedida ao inimigo com efeito comparável a um investimento de skill points do jogador. |
| Informação pré-batalha | Dados conhecidos antes do duelo, como arquétipo, buffs e características principais do inimigo. |
| Formação coerente | Conjunto de cartas, passivas, buffs e IA que compartilha uma estratégia identificável. |
